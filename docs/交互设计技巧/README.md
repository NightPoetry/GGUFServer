# 交互设计技巧

**交互设计宗旨：每个交互单独来看，都达到人类最舒适、最直觉、认知负担最小的状态。**

这个文件夹收录本项目开发过程中沉淀下来的交互设计技巧。每个技巧一个文件，
统一按四段写：**本质**（这条技巧背后的原理，一句能迁移到别处的话）、**技巧**
（可执行的规则）、**例子**（本项目里的真实案例，包括踩过的坑和被否掉的旧方案）、
**分析**（为什么这样对用户更舒服）。

这些技巧几乎都不是一次做对的——大多来自真机用出来的别扭、误触、吓一跳，
所以例子里的弯路和正路一样重要。

## 目录

### 布局与视觉

- [视觉线](视觉线.md) — 元素沿共同基准线排布，槽位提前算好，留白两端对称；美观靠规则保证，不靠每次摆
- [容器迁就内容](容器迁就内容.md) — 内容决定容器多大，容器绝不裁内容；"设上限保险"恰恰是下一次裁切的预约
- [重点会跳出来](重点会跳出来.md) — 信息按轻重分层，要紧的自己跳出来；什么都强调等于什么都没强调
- [填格子不改框架](填格子不改框架.md) — 扩展内容只能填预留的格子；本质是交互风格的一致性，一致性降低认知压力

### 手势与操作

- [非对称交互](非对称交互.md) — 触发要小、展开要大；入口按误触代价收窄，回报按意图确定性放大（卷帘门）
- [手势分家](手势分家.md) — 一个手势一个地盘，靠划地界解决冲突，不靠猜优先级
- [没用的按钮不出现](没用的按钮不出现.md) — 控件只在它有意义的时刻存在；置灰只防误触，不省认知
- [兜底入口](兜底入口.md) — 快捷方式可以做减法，但入口永远不能清零

### 动态与反馈

- [变化不瞬移](变化不瞬移.md) — 界面变化要么跟着手指、要么有过渡；节奏的主导权在用户手里
- [机器让人](机器让人.md) — 自动行为永远给用户的手动意图让路；猜不准就别猜，给个按钮
- [等待要有形状](等待要有形状.md) — 让用户等，就让他知道在等什么等到哪；先给不完美的即时结果
- [状态挂在脸上](状态挂在脸上.md) — 内部状态变化要有外显信号；尤其是一个功能改变另一个控件行为时
- [重现不重演](重现不重演.md) — 内容再次出现时不重放当初的动静；动静必须能归因到用户当下的动作

### 默认与容错

- [出厂即纯净](出厂即纯净.md) — 默认状态最少惊讶，能力全部由用户亲手知情打开
- [故障不外溢](故障不外溢.md) — 内部失败内部消化，用户最多感到"稍等了一下"；默默扛住，如实记录
