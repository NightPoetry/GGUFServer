# 技术发现库（本项目）

制度（用户令 2026-10-12）：任何排查/实验/部署/运维中的技术发现——坑、根因、解法、负结果、性能实测——**当次任务内必须立档于此**，与设计文档分开存放，供后训练与跨项目复用。

规则：
- 一条发现 = 一个文件，命名 `NNN_标题.md`，编号全局递增（编号.txt 指针，防撞号）。
- 骨架八字段：一句话结论/日期/环境/症状/根因/解法(可复现)/验证/边界与坑。
- 新建：`bash ~/.agents/skills/tech-findings/scripts/new-finding.sh "标题" "$(git rev-parse --show-toplevel 2>/dev/null || pwd)"`
- 汇报：每次立档后在回复中逐篇列出（编号+路径+一句话结论）。
