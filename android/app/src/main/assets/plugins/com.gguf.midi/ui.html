用法

让模型作曲即可，比如「写一段轻快的旋律」「来首 C 大调的小曲子」。

出来是一条可播放的乐句卡片：点按播放/停止，长按看音符。声音是端上合成的 （Web Audio 振荡器 + 包络），完全离线、不联网、不下载音源。

可以点菜：说「写一首悲伤的曲子」「来段欢快的」 「安静一点的睡前曲」——情绪对应的调式、速度、音色由插件按乐理定（悲伤＝小调 + 慢 + 弦乐）， 模型只管旋律，所以不会出现「说悲伤却给了 140 BPM 大调」。

长曲子靠多写几轮：写完一段后说「再来一段」 「接着写」，新的一段会沿用同一个调、速度、音色（风格统一），但换走向或换音区（富有变化）， 并接在已有编排后面、末尾回一次主题。每轮都能听到完整的、更长的曲子。 模型偶尔交白卷时，插件会拿主题做个变奏（移调/逆行）接上，并在回复里说明。

记谱是「片段 + 播放顺序」，模型只写片段，几十小节由插件展开：

tempo:100 key:Am
pat A: A4 C5 E5 - | G4 B4 D5 -
pat B: F4 A4 C5 - | E4 G4 B4 -
play: A A B A+12 A*2

+12／-5 = 整段移调（半音），*2 = 重复； - 延长、0 休止、| 小节线；音名与简谱都认。
可选 inst: melody=piano（还有 bell / pluck / strings）与 mix: melody=0.9 bass=0.5；低音与和声由插件按调式自动配，模型不用管。
