这是什么

把发声交给局域网上的 TTS 推理服务器——想要什么音色（克隆的游戏角色、 高质量神经网络音色）都由服务器决定，手机只负责取音播放。

服务器地址与音色在 设置 → 插件管理 → 定制音色 的设置卡片里配置。 服务器连不上时自动回退系统原声，不会无声。

推荐搭配（2026）

OpenAI 兼容模式（/v1/audio/speech）：

VoxCPM2（vLLM-Omni 部署，克隆+音色设计，MiniCPM 同门）、 Kokoro-FastAPI（轻量 82M，CPU 就能跑）、IndexTTS-2 的 OpenAI 封装（中文最强克隆）。

GPT-SoVITS 模式（/tts，api_v2）：

一分钟语料克隆角色音色（英雄联盟悠米 Yuumi、小火龙 Smolder 等 社区现成模型多走这条），填服务器上的参考音频路径即可。
